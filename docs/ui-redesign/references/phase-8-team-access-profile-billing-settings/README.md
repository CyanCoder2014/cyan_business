# Phase 8 reference intent

This phase reuses established Cyan patterns rather than introducing a separate
visual language:

- Data Manager pattern -> users/client lists and detail drawers
- Definition Editor pattern -> role/permission matrices and inspectors
- Auth/onboarding pattern -> billing and plan comparison
- Form inspector pattern -> profile and settings
- Mobile signup pattern -> mobile account forms

Do not copy sample business entities. Apply the component/layout pattern to real
IAM, billing, profile, and settings contracts.
