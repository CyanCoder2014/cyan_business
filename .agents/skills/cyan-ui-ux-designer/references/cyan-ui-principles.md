# Cyan UI Principles

## Calm, content-first minimalism

Use restrained brand accents, neutral backgrounds, thin borders, subtle
elevation, clear whitespace, and compact readable typography.

Avoid excessive gradients, large marketing headings inside the panel,
decorative glass everywhere, and multiple equally prominent actions.

## Instagram-level polish without imitation

Borrow quality principles only:

- immediate comprehension
- familiar interaction patterns
- smooth mobile ergonomics
- consistent icon rhythm
- strong empty/loading states
- content-centered hierarchy
- fast perceived response
- restrained visual noise

Do not copy Instagram navigation, brand colors, icons, or screen composition.

## Layout patterns

- Dashboard: active work and failures before vanity metrics
- AI Studio: conversation primary, draft summary contextual
- Definition editor: catalog + visual field editor + inspector
- Data Manager: definition-driven grid + record drawer
- Automation/BPM: large canvas + palette + inspector + execution/validation drawer

## Typography

- page title: 26/34 desktop, 22/30 mobile
- section title: 18/26
- card title: 15/22
- body: 14/22
- small body: 13/20
- labels: 12/18

Use weight and spacing before increasing size.

## Forms and actions

- labels above fields
- inline errors
- preserve values after backend errors
- one primary button per context
- danger styling only for destructive actions
- icon-only buttons need tooltips and accessible names
